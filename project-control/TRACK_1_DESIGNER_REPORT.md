## 3. Pedagogical & Technical Innovations

### 3.1. Unified 10-Part Standard Content Model
Every single lesson among the 30 lessons incorporates all 10 required pedagogical sections:
1. `learningObjectives`: 4 specific, behavioral outcomes per lesson.
2. `foundationalKnowledge`: Rigorous conceptual foundation without superficial fluff.
3. `technicalEvidence`: Declared source with `VERIFIED` status in Affinity 3.3.3.
4. `toolAndFeatureExplanation`: Tool name, persona, shortcut (Win/Mac split), and context options.
5. `stepByStepInstructions`: 4–5 sequential steps with shortcut tips.
6. `visualExamples`: High-density Markdown tables and ASCII architecture diagrams.
7. `guidedPractice`: Checkpoint-driven guided exercise.
8. `independentChallenge`: Capstone production prompt with verified deliverables.
9. `commonPitfalls`: 3 structured items (Mistake, Consequence, Solution).
10. `knowledgeCheck` & `summaryAndResources`: 3 multiple-choice questions with educational explanations, key takeaways, and official documentation deep links.

### 3.2. Flexible Slide Depth Progression
Following ADR-017, slide counts adapt naturally to pedagogical complexity:
- **Beginner Modules (D01–D03):** 6 to 7 slides per lesson. Focuses on muscle memory, tool introductions, and core vector geometry without overwhelming the student.
- **Intermediate Modules (D04–D07):** 8 slides per lesson. Covers multi-step workflows like gradients, layer scene graphs, typography baselines, and axonometric 3D projection.
- **Advanced Modules (D08–D10):** 9 slides per lesson. Comprehensive architectural dives into Symbols sync states, global asset libraries, hybrid raster-vector clipping, and commercial press PDF/X preflight.

### 3.3. Dual OS Shortcut Verification
All shortcuts have been rigorously verified and segregated:
- **Windows:** Uses `Ctrl`, `Alt`, `Shift`.
- **macOS:** Uses `Cmd` (`⌘`), `Option` (`⌥`), `Shift` (`⇧`).
- **Verified Persona Toggles:** `Ctrl+Alt+1` (Designer), `Ctrl+Alt+2` (Pixel), `Ctrl+Alt+3` (Export) on Windows; `Cmd+Option+1/2/3` on macOS.
- **Verified Vector Modifiers:** `Alt` (Win) / `Option` (Mac) for cusp nodes, temporary snapping bypass, and non-destructive Boolean compounds.

### 3.4. Complete Asset Transparency
In accordance with ADR-016 and user guidelines:
- 10 comprehensive production guides have been authored in `curriculum/assets/designer/`.
- Every asset declares `assetStatus: "GUIDE_DOCUMENT"`.
- Guides provide exact pixel dimensions, color hex palettes, layer naming conventions, and step-by-step checklists so students can reproduce the exact capstone designs on their local machine.

## 4. Technical Summary of Modules D01 through D10

### Module D01: Designer Interface, Personas & Canvas Setup
- **Core Topics:** Vector vs Pixel vs Export Personas, Multi-artboard setup, Document Presets (Web, Print, Photo), Color Formats (RGB/8, CMYK/8, Lab/16), Bleed geometry, Snapping Manager & Pixel Alignment.
- **Key Verification:** Document Setup (`Ctrl+Alt+P` / `Cmd+Option+P`), Snapping toggle (`Ctrl+Alt+S`), Artboard Tool (`Insert Artboard`).

### Module D02: Vector Nodes, Paths & Pen Tool Geometry
- **Core Topics:** Pen Tool modes (Pen, Smart, Polygon, Line), Node types (Sharp, Smooth, Smart), Bezier control handles, Node Tool (`A`), Rubber Band mode, Reverse Path direction.
- **Key Verification:** Alt/Option drag for cusp nodes, Shift constrain for 45° angle increments, closing paths for solid fills.

### Module D03: Advanced Shape Creation & Boolean Geometry
- **Core Topics:** Parametric shapes (Rectangles, Ellipses, Stars, Cog Tool), Corner Tool (`C`), Convert to Curves (`Ctrl+Enter` / `Cmd+Enter`), Boolean operations (Add, Subtract, Intersect, Xor, Divide), Non-destructive Compound Shapes.
- **Key Verification:** Holding Alt/Option while clicking Boolean buttons creates dynamic `(Compound)` container layers.

### Module D04: Fill, Gradient, Stroke & Pressure Profiles
- **Core Topics:** Fill Tool (`G`), 5 Gradient types (Linear, Elliptical, Radial, Conical 360° sweep, Bitmap), Midpoint position handles, Stroke Studio (Caps, Joins, Alignments), Pressure Graph curve, Contour Tool (`O`), Expand Stroke.
- **Key Verification:** Conical gradient angular rotation, Expand Stroke converting paths to closed curves.

### Module D05: Layer Organization, Masks & Clipping Paths
- **Core Topics:** Layers Studio hierarchy, Groups (`Ctrl+G`), dedicated `(Layer)` containers, Color Tagging (7 badges), Locking (`Ctrl+L`), Vector Clipping (nested child curves), Vector Masking (grayscale opacity masks), Blend Modes, Isolation Mode.
- **Key Verification:** Alt/Option click on layer thumbnail enters Isolation Mode; Dragging a layer onto another layer until indented creates a child clipping mask.

### Module D06: Typography, Text-on-Path & Glyph Styling
- **Core Topics:** Artistic Text vs Frame Text, Text frame reflow vs font scaling, Micro-kerning (`Alt+Left/Right Arrow`), Tracking, Leading overrides, Text-on-Path, Green/Red margin handles, Reverse Path Winding, OpenType features (Ligatures, Swashes, Stylistic Alternates), Glyph Browser, Text Styles hierarchy.
- **Key Verification:** Double-click on curve with Text Tool converts curve into Text-on-Path baseline; Reverse Curve flips text orientation.

### Module D07: Isometric Grids, 3D Projections & Snapping
- **Core Topics:** Grid and Axis Manager (`Ctrl+Alt+G`), Advanced mode, True 30°/150°/90° isometric math vs 2:1 pixel isometric (26.565°), Grid toggle (`Ctrl+'`), Snap-to-grid toggle (`Ctrl+Alt+'`), Isometric Studio, Front/Side/Top planes, Fit to Plane (affine transform matrix), Edit in Plane mode, Snapping Candidates (magenta outlines, max 6 FIFO pool), Intersection Snapping, Outline view (`Ctrl+Y`).
- **Key Verification:** One-click SSR replacement via Fit to Plane; live typography preservation in projected 3D space.

### Module D08: Symbols, Linked Assets & Component Systems
- **Core Topics:** Symbols Studio, Master creation, Multi-instance bidirectional linking, Sync toggle (Sync ON = global propagation, Sync OFF = local overrides), Detach button consequences, Assets Studio, Categories & Subcategories, Exporting/Importing `.afassets` bundles, StudioLink cross-app asset sharing, Nested Symbols, Constraints Studio (edge pinning, fixed width/height), Global Color Swatches as design tokens.
- **Key Verification:** Triangle badge marking live Global Swatches in palette; Constraints edge pinning protecting circular icons during card width resizing.

### Module D09: Pixel Persona Integration & Textured Vector Shading
- **Core Topics:** Pixel Persona (`Ctrl+Alt+2`), Paint Brush Tool (`B`), Raster brush categories (Dry Media, Texture, Inks), Flow vs Opacity mechanics, Pressure Jitter, More dialog, Child pixel layer nesting inside vector parent shapes, Dynamic live node reshaping without pixel stretching, Protect Alpha mode (transparency locking), Color Studio procedural vector noise (clicking Opacity well), Resolution governance (300 DPI print standard).
- **Key Verification:** Low Flow (15%–25%) creates velvety non-banding grain; child pixel layers remain non-destructively clipped to vector bezier paths.

### Module D10: Vector Export, Slices & Production Output
- **Core Topics:** Export Persona (`Ctrl+Alt+3`), Slices Tool (`S`), Document slices, Artboard slices, Layer-based slices (dynamic bounding box tracking), Slices Studio manifest, Multi-density scaling (1x, 2x, 3x), Modern formats (PNG-24, WebP, JPEG XL, SVG), Continuous Export engine (background re-rendering on document save), Clean SVG optimization (`viewBox`, 2 decimal places, flatten transforms, Text as Curves, zero base64 blobs), Press-Ready PDF/X standards (PDF/X-1a vs PDF/X-4), 3mm document bleed, Printer crop marks and registration targets.
- **Key Verification:** Continuous Export auto-updates files upon `Ctrl+S`; SVG output contains clean `<svg viewBox="0 0 24 24">` without base64 raster blobs.
