# AFFINITY DESIGNER PRACTICE GUIDE — MODULE D06
## Typography, Text-on-Path & Glyph Styling Practice Guide

**Module ID:** `D06`  
**Difficulty:** Intermediate  
**Track:** Affinity Designer  
**Asset Status:** `GUIDE_DOCUMENT`  
**Target File:** Manual canvas setup in Affinity Designer 3.3.3  

---

### 1. Document Setup Instructions
1. Open Affinity Designer 3.3.3.
2. Create a new document: `Print > A4` or `Web > FHD (1920 x 1080 px)`.
3. Check **Create Artboard** and click **Create**.

---

### 2. Practice Exercises

#### Exercise 1: Artistic Text vs Frame Text (Lesson D06-01)
- Select the **Artistic Text Tool (`T`)**:
  - Click and drag on the canvas to set initial font point size, then type `AFFINITY ACADEMY`.
  - Drag the corner handle with the Move Tool (`V`): notice the font size scales dynamically!
- Select the **Frame Text Tool**:
  - Click and drag a rectangular bounding box. Insert filler text (`Text > Insert Filler Text`).
  - Drag the corner handle: notice the text reflows within the frame instead of scaling the letterforms.
- Test micro-typography shortcuts:
  - Place cursor between two letters: hold **`Alt` (Win) / `Option` (Mac)** and press **Left/Right Arrow** to adjust manual kerning by 10‰.
  - Select a line of text: hold `Alt` / `Option` and press **Up/Down Arrow** to adjust tracking/leading.

#### Exercise 2: Text-on-Path & Circular Badge (Lesson D06-02)
- Draw a circle using the Ellipse Tool (`M`).
- Select the **Artistic Text Tool (`T`)** and hover over the outline edge of the circle until the cursor changes to a 'T' with a wavy diagonal curve.
- Click on the circle path. Type `★ MASTER OF VECTOR GRAPHICS ★`.
- Notice the two on-canvas locator handles:
  - **Green Triangle:** Start of text margin.
  - **Red Triangle:** End of text margin.
- Drag the handles to position text along the upper arc.
- On the Context Toolbar, click **Reverse Direction** to flip text inside or outside the arc, and adjust **Baseline Offset**.

#### Exercise 3: OpenType Features & Glyph Browser (Lesson D06-03)
- Open the **Typography Studio** (`View > Studio > Typography`) and **Glyphs Studio** (`View > Studio > Glyphs`).
- Type sample text using an OpenType-rich typeface (such as a serif or script font).
- In the Typography Studio:
  - Toggle **Standard Ligatures** (fi, fl, ffi).
  - Toggle **Discretionary Ligatures** (ct, st).
  - Enable **Stylistic Alternates** and **Swashes** to witness decorative character flourishes.
- In the Glyphs Studio:
  - Filter by 'Alternates for Selection' to inspect all available variant glyphs.
