# AFFINITY DESIGNER — STARTER ASSET SPECIFICATION (MODULE D01)
## Document Preset: Multi-Device Responsive Artboard Canvas

### 1. File Metadata
- **Module ID:** `D01` (Designer Interface, Personas & Canvas Setup)
- **Lessons:** `D01-01`, `D01-02`, `D01-03`
- **Application:** Affinity Designer 3.0+
- **Primary Persona:** Vector Persona
- **Status:** **VERIFIED SPECIFICATION**

---

### 2. Manual Canvas Setup Parameters (Desktop App)
Open Affinity Designer and press `Ctrl+N` (Windows) / `Cmd+N` (macOS):
1. **Document Type:** Web / Device
2. **Page Width:** `1920 px`, **Height:** `1080 px`
3. **Color Format:** `RGB/8`, **Profile:** `sRGB IEC61966-2.1`
4. **Resolution:** `72 DPI` (Web standard) or `144 DPI` (Retina)
5. **Artboards:** Check `[x] Create Artboard` (Artboard Name: `Desktop-1920`)

### 3. Adding Additional Artboards
Using the **Artboard Tool** (`Insert Artboard` button on Context Toolbar):
- Artboard 2: **Tablet Viewport** — `768 px` wide x `1024 px` high
- Artboard 3: **Mobile Viewport** — `375 px` wide x `812 px` high

### 4. Snapping & Grid Configuration
- Turn on Snapping (`Ctrl+;` / `Cmd+;`).
- Enable **Snap to Artboards**, **Snap to Object Bounding Boxes**, and **Include Bounding Box Midpoints**.
- Activate **View > Show Grid** (`Ctrl+'` / `Cmd+'`) with an 8px base unit grid.
