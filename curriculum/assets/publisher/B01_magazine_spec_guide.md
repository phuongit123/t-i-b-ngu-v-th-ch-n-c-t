# AFFINITY PUBLISHER — STARTER ASSET SPECIFICATION (MODULE B01)
## Publication Preset: Editorial Editorial Magazine Spread (A4 Facing Pages)

### 1. Publication Metadata
- **Module ID:** `B01` (Publication Architecture, Document Setup & Bleed)
- **Lessons:** `B01-01`, `B01-02`, `B01-03`
- **Application:** Affinity Publisher 3.0+
- **Primary Persona:** Publisher Persona
- **Status:** **VERIFIED SPECIFICATION**

---

### 2. Document Setup Parameters
Open Affinity Publisher and press `Ctrl+N` (Windows) / `Cmd+N` (macOS):
1. **Category:** Print / Press Ready
2. **Page Preset:** `A4` (`210 mm` x `297 mm`, Portrait)
3. **Facing Pages:** Check `[x] Facing Pages` (Spreads)
4. **Arrange:** Horizontal, Start on: `Right` (Standard book/magazine cover start)
5. **Page Count:** `8 pages` (or multiples of 4 for print signatures)
6. **Color Format:** `CMYK/8`, **Profile:** `Coated FOGRA39` or `U.S. Web Coated (SWOP) v2`

### 3. Margins & Bleed Configuration
- **Margins:**
  - Top: `20 mm`
  - Inner (Gutter): `25 mm` (essential allowance for binding spine)
  - Outer: `18 mm`
  - Bottom: `22 mm`
- **Bleed:**
  - All sides: `3.0 mm` (Standard European / ISO commercial print standard)
  - Check `[x] Include Bleed in Preview`

### 4. Baseline Grid & Column Guidelines
- **View > Baseline Grid Manager:**
  - Check `[x] Use Baseline Grid`
  - Grid Spacing: `12 pt` (or `14 pt` matching body font leading)
  - Start Position: Align to Top Margin
- **Text Frame Columns:**
  - Standard Editorial Grid: `3 columns`, Gutter: `5 mm`
